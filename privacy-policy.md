# Privacy Policy for Facebook NPC Marker
### Last updated: March 10, 2026

## Overview

Facebook NPC Marker is a browser extension designed to visually highlight comments on Facebook made by profiles included in a predefined list. The extension operates entirely within the user’s browser and is intended solely to improve the user’s browsing experience.

## Data Collection

Facebook NPC Marker does not collect, store, transmit, or share any personal data.

The extension:
- Does not collect user information
- Does not track browsing activity
- Does not send any data to external servers
- Does not use analytics or telemetry

## Local Processing

The extension works by:
- Loading a local JSON file included within the extension package.
- Comparing identifiers found in Facebook comment elements with identifiers in that file.
- Visually highlighting matching comments and adding a small marker icon.

All processing occurs locally in the user's browser.

## Permissions

The extension runs only on pages under:

https://facebook.com/*

https://www.facebook.com/*

This access is required solely to detect comment elements and apply visual highlights.

The extension does not read, modify, or store any user account information outside of the comment elements necessary for highlighting.

## Data Storage

Facebook NPC Marker does not store any user data locally or remotely.

## Third-Party Services

This extension does not use any third-party services, APIs. The initial datasource is based on a [public article](https://telex.hu/techtud/2026/03/09/mutatjuk-a-fideszes-kamuprofil-halozat-mind-az-1198-tagjat).

## Changes to This Policy
